# fitzyracing1.blog

Personal blog of Joshua Almeida, published with GitHub Pages at [fitzyracing1.blog](https://fitzyracing1.blog).

Until DNS for the custom domain is pointed here, the site is also at [fitzyracing1.github.io/blog](https://fitzyracing1.github.io/blog/).

## Add a post

1. Create a file in `_posts/` named `YYYY-MM-DD-short-title.md`.
2. Start it with this front matter:

   ```yaml
   ---
   layout: post
   title: "Your title"
   date: YYYY-MM-DD
   ---
   ```

3. Write the post in Markdown below the front matter.
4. Commit and push to `main`. GitHub Pages will build and publish the site.

The site uses the [minima](https://github.com/jekyll/minima) theme. Site settings live in `_config.yml`.
